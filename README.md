# ml-amazon-project
# ML Demand Forecasting (Amazon Sales)

## 📌 Описание проекта
Учебный ML-проект по прогнозированию спроса на товары по категориям на следующий месяц
на основе исторических данных о продажах Amazon.

Проект выполнен в рамках командной работы, моя роль — анализ данных, feature engineering,
обучение и оценка ML-моделей.

## 🎯 Бизнес-задача
Неправильное планирование запасов приводит либо к дефициту товаров, либо к перепроизводству.
Цель проекта — помочь бизнесу прогнозировать спрос и принимать более обоснованные решения
по управлению запасами.

## 🧩 Подзадачи
1. Прогноз количества покупок (регрессия)
2. Предсказание спада спроса (бинарная классификация)
3. Выявление ключевых факторов спроса (интерпретация моделей)
4. Учет сезонности и временной динамики (time series)

## 🧠 Используемые методы
- Предобработка и агрегация временных данных
- Feature engineering (лаги, тренды, сезонность)
- Линейная регрессия
- Random Forest, Balanced Random Forest, CatBoost
- ARIMA / SARIMA
- Метрики: MAE, RMSE, R², Recall, Precision

## 📊 Основные результаты
- Для временных рядов модель **SARIMA** показала наилучшее качество (R² ≈ 0.88)
- CatBoost позволил значительно снизить риск пропуска спадов спроса
- Выявлены ключевые драйверы спроса (скидки, выручка, категория товара)
- Модель применима для базового планирования запасов по крупным категориям
